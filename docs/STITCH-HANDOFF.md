# Stitch handoff prompts

Use these with the PRD when Stitch access is available. They are prepared prompts, not evidence that Stitch ran.

## First design

Design desktop and mobile versions of Asta’s Preparation Dashboard. Use charcoal #111214, warm white #f5f1e9, and restrained coral #ec786c. Include a short Asta preparation goal, compact Lucifero gravity threat brief, three task cards, and a completed/total and percentage summary. Use only Sword control (High), Physical endurance (Medium), Team coordination (High), with the exact descriptions from PRD.md. Each card has an accessible completion checkbox and visible Complete/Incomplete status. All tasks start incomplete; they can be undone. Show 0/3 and 0%, with the plan-completion explanation and session-only refresh note. Use readable 16px descriptions, strong contrast, 44px interaction targets, and visible keyboard focus. No accounts, task editing, navigation, chatbot, or decorative action buttons. Progress weights every task equally and does not predict victory. Show the 360px single-column layout and desktop task/sidebar layout.

## Required refinement

Review your first result for small text and missing mobile status. Enlarge task descriptions to at least 16px. Make Complete/Incomplete explicit on every mobile task card and leave enough space below each control. Remove any out-of-scope features. Retain genuine before and after screenshots, explain the improvement, and record the shareable project link if available.
